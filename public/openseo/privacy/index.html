OpenSEO — Forge: privacy and Google data use

Operator and contact: Michael, Forge; 2313745ontarioinc@gmail.com.

Data accessed

With the account holder's permission, OpenSEO — Forge accesses their Google account identifier, email address and profile information, plus read-only Google Search Console information for properties they can access. Search Console information includes site identifiers, search queries, page URLs, dates, clicks, impressions, click-through rates and average positions.

If the account holder separately connects Google Analytics, the app requests read-only Analytics access. This can cover Analytics data accessible to that Google account. The operator selects existing GA4 properties for project reporting. Data can include account, property and stream identifiers; website URLs and measurement IDs; reporting time zones; measurement settings and custom dimension/metric definitions; and aggregated users, sessions, acquisition sources, pages, engagement, events, key events, site-search terms, device/country summaries and ecommerce transactions, items and revenue where collected.

Purpose

This information is used to connect the correct Google account, display search and website performance, investigate visibility and visitor outcomes, and prepare operator-requested analysis and reports. The Google connections do not request website-editing, Search Console write or Analytics management permissions. Connecting Analytics does not install tracking, create a property or change collection settings.

Storage and access

The self-hosted workspace stores account-connection details, project/property mappings and any saved reports. Google access and refresh tokens are encrypted at rest. Cloudflare provides access control and request routing.

Authorized AI clients can request Search Console and connected Analytics results and saved reports through the workspace's MCP connection. If the operator uses an AI provider, the information supplied to that provider is processed under that provider's terms and the operator's account settings. Such access should be limited to the data needed for the requested task.

Retention and removal

The operator retains connection information while it is needed for the integration and retains saved reports until they are removed. Disconnecting or revoking Google access stops future authorized retrieval but does not automatically erase previously saved reports, exported copies or existing backups. Contact the operator to request removal of retained data and review backup retention.

Your choices

You can revoke the app's authorization in your Google Account's third-party connections settings. You can ask the operator to remove the Google connection, affected project mappings and saved material. Removing access may prevent connected features from working. Because the integrations share one Google app, revoking that app in Google may interrupt both Search Console and Analytics; disconnecting an Analytics project in OpenSEO is a separate action.

Use restrictions

Google user data will be used only to provide the described SEO features and requested analysis. It will not be sold or used for advertising targeting. Any transfer to an authorized tool must be necessary for that requested functionality and comply with the Google API Services User Data Policy.

Security and changes

Access is restricted, transport uses HTTPS, and credentials are not published in reports. No system can guarantee absolute security. Material changes to this app's Google-data practices should be reflected here before those practices change.
