OpenSEO — Forge

OpenSEO — Forge is a private, self-hosted SEO workspace operated by Michael for Forge. It helps the operator review Google Search Console performance for websites they are authorized to manage.

The Google connection requests read-only Search Console access and basic Google account identity. It displays clicks, impressions, click-through rate, average position, queries and pages. It does not request permission to change a website or edit Search Console data.

Access to the workspace is restricted. Authorized AI clients may retrieve selected data when the operator asks them to analyze it or prepare reports.
